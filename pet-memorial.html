4️⃣ 프레임별 포즈 생성 (Gemini)

선택 0

대표 이미지를 기준으로 프레임마다 다른 포즈의 이미지를 생성합니다. 카드 좌상단의 ☐을 눌러 2~3개를 선택 후 ↻ 선택 재생성으로 한 번에 다시 만들 수 있습니다.

5️⃣ 동영상 클립 생성 (Kling)

선택 0

생성된 프레임들로 Kling이 모션 영상을 만듭니다. 카드 좌상단의 ☐을 눌러 2~3개를 선택 후 ↻ 선택 재생성으로 한 번에 다시 만들 수 있습니다.

⏳ 이미지 생성 중에는 영상 클립을 만들 수 없습니다. 이미지가 완료된 후 다시 시도하세요.

🌟 대표 이미지 (Hero) 프롬프트

마법사 첫 단계에서 만들어지는 대표 이미지 전용 프롬프트입니다. 두 가지 스타일 중 하나를 선택하세요.

단일: 정면 한 컷의 자연스러운 포즈. 빠르고 단순.
캐릭터 시트: 같은 피사체의 정면·3/4·측면·후면(또는 표정) 4컷을 한 장에 모은 reference sheet. 이후 frame 생성 시 identity 가 훨씬 강하게 유지됨.

🎬 동영상 합성

📝 동영상 프롬프트

각 동영상의 모션 프롬프트, 첫번째/마지막 프레임, 길이를 설정합니다.

🎵 BGM

🎛 사용 모델 선택

각 단계마다 어떤 AI 모델을 사용할지 선택합니다. 기본값은 Gemini / Kling 으로, 변경하지 않으면 기존과 동일하게 동작합니다.

Gemini

Google AI Studio에서 발급한 Gemini API 키를 입력합니다.

OpenAI (Images 2.0)

OpenAI Platform에서 발급한 API 키를 입력합니다. → 키 발급

Kling

Kling AI 개발자 포털에서 발행된 API 키를 입력합니다.

Cloudflare Workers + R2로 호스팅됩니다. 비워두면 기본값 자동 적용.

Seedance 2.0 (ByteDance · via Replicate)

Replicate 토큰을 입력합니다. → 토큰 발급 · → Seedance 2.0 모델 페이지

Seedance 2.0 만 해상도 옵션 지원. 1.x 모델은 무시됨.
